# docs

プロジェクトとしての設計・運用資料を置く。

| ディレクトリ | 内容 |
| --- | --- |
| `adr/` | 設計上の意思決定記録（Architecture Decision Record） |
| `runbooks/` | 運用手順。正常時の操作と、失敗時の切り分けを書く |
| `security/` | 脅威モデルとデータ分類。何を、誰から守るのかを先に決める |

学習用のメモは `x-docs/`、計画と進捗は `x-plan-改訂/` にあり、こことは役割が異なる。
ここに置くのは「別の人が同じことを再現できるか」を基準にした資料に限る。

ファイル名はリポジトリの慣習に合わせ、連番と作成日を接頭辞に付ける。
