## 何を対象外にしているか

計画上の Stage 2 のうち、次の3つである。

| 枠 | 内容 | 対象外である理由 |

| W14 | IaC | Docker Compose 以上の基盤定義を扱わない。構成は単一ホストに閉じている |
| W15 | チーム標準 | 利用者が1名であり、合わせる相手がいない |
| W16 | コスト管理 | 課金の対象となる資源を使っていない |

## この一覧に残す理由

W15 は、文書としては 60番台（コーディング規約・レビュー基準・Git 運用規約・ドキュメント管理規程）
として整備の対象になっている。実装としての「チーム標準」は対象外のままだが、
文書としては 60・62・63・64 が受け持つ。この2つを混同しないために残す。

61（アーキテクチャ規約）は既に作成済みであり、W15 の対象外とは別に扱っている。

## 再検討する条件

ML 運用へ戻る判断が出たとき。または、利用者が2名以上になったとき（W15 のみ）。
