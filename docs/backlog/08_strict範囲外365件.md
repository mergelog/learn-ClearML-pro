## 何が起きているか

Angular の厳格な型検査は、移行済みの範囲に対してのみ通している。
範囲外には365件の指摘が残っている（2026-09-12 時点）。

範囲外の大半は取り込んだ ClearML Web であり、凍結方針の対象である。
そのため「直す」ことは、凍結領域へ手を入れることを意味する。

## いまの扱い

範囲を広げないかぎり、この365件は検査に現れない。
`pnpm web:typecheck:strict` は移行済み範囲だけを見るので、緑のままである。

増やさないことは別の検査が担う。ESLint の指摘件数は上限として固定してあり、
`pnpm web:lint:baseline` が増加を検出する。

## 解決とみなす状態

範囲を広げた分だけ件数が減っていること。全件をなくすことを目標に置かない。
凍結領域を触る判断は、それ自体が別の決定である。

## 着手の条件

無し。凍結領域のファイルを別の理由で触るとき、そのファイルを範囲へ入れる。
