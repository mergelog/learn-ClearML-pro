## 何が起きているか

状態は Docker の名前付きボリュームにある。取得・保存・復旧のいずれについても、
手順も仕組みも無い。

| ボリューム | 失ったときに起きること |
| --- | --- |
| `clearml-mongo-db` | 実験とモデルの一切を失う |
| `clearml-elasticsearch` | 実験の記録（指標・コンソール出力）が読めなくなる |
| `clearml-files` | 学習済みモデルと Artifact を取得できなくなる |

RPO と RTO も、バックアップが無いため目標を置けない。

## いまの手当て

`docker volume prune` と `docker system prune --volumes` を実行しない、という運用上の制約だけがある。
これは誤って消すことを避けるものであり、失われたものを取り戻す手段ではない。

## 解決とみなす状態

取得の手順があり、その手順で取ったものから実際に復旧できることを一度確かめてあること。
確かめていない復旧手順は、手順が無いのとあまり変わらない。

## 着手の条件

失って困るデータが生まれたとき。現在の Dataset は生成し直せ、モデルは学習し直せる。
実測値や、再現できない実行の記録が積み上がった時点で、条件が満たされる。
