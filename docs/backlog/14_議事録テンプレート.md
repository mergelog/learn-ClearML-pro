# BL-14: 議事録テンプレート（75）が作れない

## 何が起きているか

`x-plan-改訂/_old/20_ドキュメント作成プラン.md` §11 は `75_議事録テンプレート.md` を挙げている。
しかし本プロジェクトに会議体が無い。作業者は1名であり、打ち合わせも、参加者も、決議も存在しない。

テンプレートだけを置くことはできる。ただしそれは、記入される見込みの無い様式であり、
プラン §15 が禁じる「実在しない運用体制を作る」に当たる。

単独作業で決めたことの記録先は既にある。方式・技術・方針の選択は ADR（`../_archive/adr/` の10本）が、
決定を後から変えた事実は 76（変更管理台帳）が持つ。議事録が埋めるべき隙間は、現状では空いていない。

## 解決とみなす状態

会議体が生まれたときに、次を満たす様式が `docs/phase8_プロジェクト管理/75_議事録テンプレート.md` にあること。

* 日時・参加者・議題・決定事項・未決事項・次の行動と期限の欄を持つ
* 決定事項のうち方式・技術・方針に当たるものを ADR へ移す経路が書いてある
* 議事録と ADR と 76 の役割分担が書いてある（同じ決定を3か所に書かない）

## 着手の条件

作業者が2名以上になり、同期的に何かを決める場ができたとき。
73 §4.4（複数人になったときの割り当て）を適用する時期と同じである。
