# 01-02 行クリックから Info パネル表示まで

一覧の行をクリックしたときと、ダブルクリック（またはカード表示での選択）したときで、
到達点が違う。前者はコンポーネント内の signal を書き換えるだけで URL は動かない。
後者は Action を発行し、Effects が `router.navigate()` してから右ペインが開く。

## 図1: シングルクリック（ハイライトのみ）

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant PT as p-table
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    User->>PT: 行をクリック
    PT->>SmTable: (click) → rowClicked.emit({e, data})
    SmTable->>ExpTable: (rowClicked)="tableRowClicked($event)"
    ExpTable->>ExpTable: selectionMode() === 'single' を確認
    ExpTable->>EC: experimentSelectionChanged.emit({experiment, origin: 'row'})
    EC->>EC: minimizedView() が false かつ origin==='row'
    EC->>EC: selectionState().highlited.update(cur => cur?.id === id ? null : exp)
    Note right of EC: dispatch なし。URL も Store も変わらない<br/>同じ行を再クリックするとハイライト解除
    EC-->>ExpTable: [selectedExperiment]=highlited() が更新される
```

## 図2: ダブルクリック（Info パネルを開く）

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent
    participant Store
    participant ViewEff as ViewEffects
    participant Router
    participant Outlet as ExperimentOutputComponent

    User->>ExpTable: 行をダブルクリック
    ExpTable->>EC: experimentSelectionChanged.emit({experiment, openInfo: true, origin: 'table'})
    EC->>Store: dispatch experimentSelectionChanged({experiment, project})
    Store->>ViewEff: ofType(experimentSelectionChanged)
    ViewEff->>Router: navigate(['projects', project, 'tasks', exp.id])
    ViewEff->>Store: dispatch setTableMode({mode: 'info'})
    Router->>Outlet: :experimentId ルートを活性化（lazy load）

    Note over EC,Store: URL 変化が EC 側の購読にも返ってくる
    Store-->>EC: selectRouterParams（experimentId あり）
    EC->>EC: selectExperimentFromUrl() の combineLatest が発火
    EC->>Store: dispatch setSelectedExperiment({experiment})
    EC->>Store: dispatch setTableMode({mode: tableMode()})
    Store-->>EC: selectMinimizedView → true
    Note right of EC: minimizedView() が true になり<br/>as-split の右ペインが表示される
```

## 読みどころ

- 行クリックの受け口: [experiments-table.component.ts:334](../../../src/app/webapp-common/experiments/dumb/experiments-table/experiments-table.component.ts:334)
- 親側の分岐: [experiments.component.ts:542](../../../src/app/webapp-common/experiments/experiments.component.ts:542)
- URL から選択を復元する購読: [experiments.component.ts:479](../../../src/app/webapp-common/experiments/experiments.component.ts:479)
- 遷移を行う Effect: [common-experiments-view.effects.ts:388](../../../src/app/webapp-common/experiments/effects/common-experiments-view.effects.ts:388)
- 実際に `router.navigate` する関数: [common-experiments-view.effects.ts:743](../../../src/app/webapp-common/experiments/effects/common-experiments-view.effects.ts:743)

`minimizedView` は Store のフラグではなく、ルートパラメータから導出される Selector である
（`experimentId` があるか、`ids` があれば true）。
パネルの開閉状態を別途保持していないため、URL を直接開いた場合も同じ見た目になる。

- 導出元: [projects.reducer.ts:106](../../../src/app/webapp-common/core/reducers/projects.reducer.ts:106)

詳細パネルが表示された後、中身のデータを取りに行く流れは
[04-04 詳細パネルの二段取得](../04_バックエンド経路/04-04_詳細パネルの二段取得.md) を参照。
