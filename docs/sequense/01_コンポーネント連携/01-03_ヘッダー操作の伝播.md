# 01-03 ヘッダー操作の伝播

`sm-experiment-header` は `dispatch` を一切行わず、20 個近い `output` を
すべて `ExperimentsComponent` に投げ返す。
Store から読むのは基底クラスの `selectMaxDownloadItems`（CSV の最大件数表示）だけである。
親側は同じハンドラの中で `getTableModeFromURL()` を見て、テーブルモードと比較モードで
発行する Action を切り替えている。

## 図1: カスタム列の追加（メトリクス列）

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Menu as sm-custom-cols-menu
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Store
    participant ViewEff as ViewEffects

    User->>Menu: 列カスタマイズのメニューを開く
    Menu->>Header: getMetricsToDisplay.emit()
    Header->>EC: (getMetricsToDisplay)="getMetricsToDisplay()"
    EC->>Store: dispatch getCustomMetrics({hideLoader: true})
    EC->>Store: dispatch getCustomHyperParams()
    Note right of Store: 選択肢の取得は 04-03 を参照
    Store-->>Header: [metricVariants] / [hyperParams] が埋まる

    User->>Menu: メトリクスを1つ選ぶ
    Menu->>Header: selectedMetricToShow.emit({variant, valueType, addCol})
    Header->>EC: (selectedMetricToShow)
    alt テーブルモード
        EC->>EC: createMetricColumn(...) で ISmCol を組み立て
        EC->>Store: dispatch addColumn({col}) または removeCol({id, projectId})
        EC->>Store: dispatch updateUrlParams()
        Store->>ViewEff: setURLParams effect → URL の columns を書き換え
    else 比較モード
        EC->>Store: dispatch addSelectedMetric / removeSelectedMetric
        Note right of Store: 比較モードの選択列は URL ではなく<br/>localStorage と Store に残る（02-01）
    end
```

## 図2: アーカイブ切替（確認ダイアログを挟む）

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Base as BaseEntityPageComponent
    participant Dialog as ConfirmDialogComponent
    participant Router
    participant Store

    User->>Header: Live / Archive トグル
    Header->>EC: isArchivedChanged.emit(archived)
    EC->>Base: archivedChanged(archived)
    Base->>Store: select(selectNeverShowPopups) を take(1)
    alt 選択中の項目があり「二度と表示しない」未設定
        Base->>Dialog: open(ConfirmDialogComponent)
        User->>Dialog: Proceed
        Dialog-->>Base: afterClosed() → confirmed
    else 選択なし
        Note right of Base: ダイアログを出さずそのまま遷移
    end
    Base->>Store: dispatch setTableMode({mode: 'table'})
    Base->>Router: navigate([], {queryParams: {archive}})
    Base->>EC: afterArchiveChanged()
    EC->>Store: dispatch showOnlySelected({active: false})
    Base->>Store: dispatch resetProjectSelection()
```

## 図3: そのほかのヘッダー output と行き先

```mermaid
sequenceDiagram
    autonumber
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Store

    Header->>EC: (setAutoRefresh)
    EC->>Store: dispatch setAutoRefresh({autoRefresh})
    Header->>EC: (clearSelection)
    EC->>Store: dispatch clearHyperParamsCols({projectId})
    Header->>EC: (clearTableFilters)
    EC->>Store: dispatch setTableFilters([]) + tableFilterChanged(空値)
    Header->>EC: (tableModeChanged)
    EC->>EC: modeChanged(mode) → 01-06 へ
    Header->>EC: (downloadTableAsCSV)
    EC->>EC: table().table().downloadTableAsCSV(...) ※API を使わない
    Header->>EC: (downloadFullTableAsCSV)
    EC->>Store: dispatch prepareTableForDownload({entityType: 'task'})
    Header->>EC: (removeColFromList)
    EC->>Store: dispatch resetSortOrder?（ソート中の列なら） + removeCol + updateUrlParams
```
