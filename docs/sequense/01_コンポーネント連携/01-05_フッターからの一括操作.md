# 01-05 フッターからの一括操作

フッターは 2 件以上チェックされたときだけ現れる。
ボタンの押下は `ExperimentsComponent` を経由して、コンテキストメニューのコンポーネントの
メソッド呼び出しに変換される。つまりフッターとコンテキストメニューは同じ処理を共有している。

## 図1: チェックボックス選択からフッター表示まで

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent
    participant Store
    participant ViewEff as ViewEffects
    participant Footer as sm-entity-footer

    User->>ExpTable: 行のチェックボックスをクリック
    ExpTable->>ExpTable: rowSelectedChanged() → getSelectionRange()（Shift 範囲選択に対応）
    ExpTable->>EC: experimentsSelectionChanged.emit([...checked, ...add])
    EC->>Store: dispatch setSelectedExperiments({experiments})

    Store->>ViewEff: ofType(setSelectedExperiments)
    ViewEff->>ViewEff: MenuItems ごとに selectionDisabledXxx() を計算
    ViewEff->>Store: dispatch setSelectedExperimentsDisableAvailable({...})

    Store-->>EC: checkedExperiments$ / selectedExperimentsDisableAvailable$
    EC->>EC: createFooterState() の combineLatest（debounceTime 100ms）
    Note right of EC: filter(selected.length > 1 || ...) を通らないと値が出ない
    EC->>Footer: [footerState] [footerItems]
    Footer->>Footer: 各 ItemFooterModel が自分の活性状態を決める
```

## 図2: 「Archive」押下からサーバ更新まで

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Footer as sm-entity-footer
    participant EC as ExperimentsComponent
    participant Menu as sm-experiment-menu-extended
    participant Store
    participant MenuEff as MenuEffects
    participant TasksApi

    User->>Footer: Archive ボタン
    Footer->>EC: footerItemClick.emit({item, emitValue})
    EC->>EC: singleRowContext = false
    EC->>EC: setTimeout(() => switch(item.id))
    EC->>Menu: contextMenu().restoreArchive(entitiesType)
    Note over EC,Menu: フッターは自前の処理を持たず、<br/>メニュー側のメソッドを呼ぶだけ
    Menu->>Store: dispatch archiveSelectedExperiments({selectedEntities})
    Store->>MenuEff: ofType(archiveSelectedExperiments)
    MenuEff->>TasksApi: tasksArchiveMany({ids})
    TasksApi-->>MenuEff: {failed: []}
    MenuEff->>Store: dispatch setSelectedExperiments({experiments: []})
    MenuEff->>Store: dispatch removeExperiments({experiments: successIds})
    MenuEff->>Store: dispatch getExperiments()
    MenuEff->>Store: dispatch addMessage(Undo 付き通知)
    Store-->>Footer: checkedExperiments が空 → フッターが閉じる
```

## `item.id` とメニューメソッドの対応

| フッター項目 | 呼ばれるメソッド |
| --- | --- |
| `showAllItems` | `EC.showAllSelected(!emitValue)`（Store の `showOnlySelected`） |
| `compare` | `EC.compareExperiments()`（`compare-tasks` へ遷移） |
| `archive` | `contextMenu().restoreArchive(entitiesType)` |
| `reset` / `publish` / `retry` | `resetPopup()` / `publishPopup()` / `retryPopup()` |
| `enqueue` / `dequeue` | `enqueuePopup()` / `dequeuePopup()` |
| `delete` | `deleteExperimentPopup()` |
| `abort` / `abortAllChildren` | `stopPopup()` / `stopAllChildrenPopup()` |
| `moveTo` | `moveToProjectPopup()` |
