# 01-06 比較モードへの切替

テーブルモードは `table` / `info` / `compare` の 3 状態を取る。
Store の `tableMode` と URL の形は別々に管理されており、`getTableModeFromURL()` が
URL 側の「正解」を読み、`modeChanged()` が Store と URL の両方を合わせに行く。

## 図1: ヘッダーのトグルから比較ビュー表示まで

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Store
    participant Router
    participant Guard as compareNavigationGuard
    participant Charts as ExperimentCompareScalarCharts

    User->>Header: モードトグルで compare を選択
    Header->>EC: tableModeChanged.emit('compare')
    EC->>EC: modeChanged('compare')
    EC->>Store: dispatch setTableMode({mode: 'compare'})
    EC->>EC: setTimeout(() => createFooterItemsRunner(), 100)
    EC->>EC: setTimeout(() => dispatch getSelectedExperiments({ids: URL の ids}))
    EC->>Router: navigate(['compare'], {relativeTo: route, queryParamsHandling: 'preserve'})

    Router->>Guard: canActivate
    Guard->>Store: selectTableCompareUrlParts（view と選択中 ids）を読む
    Guard->>Router: createUrlTreeFromSnapshot で<br/>compare/scalars（ids=a,b 付き）へ振り替え
    Router->>Charts: compareViewStateGuard → setCompareView → loadComponent()

    EC->>Header: [tableCols] を compareSelectedMetricsScalars$ に差し替え
    Note right of EC: tableMode() === 'compare' の間だけ<br/>ヘッダーの列リストが「選択中メトリクス」になる
    EC-->>EC: highlited() が null を返す（比較中は行ハイライトを消す）
```

## 図2: scalars と plots の切替

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Store
    participant Router

    User->>Header: Scalars / Plots を切替
    Header->>EC: compareViewChanged.emit('plots')
    EC->>Store: dispatch setCompareView({mode: 'plots'})
    EC->>Router: navigate(['compare'], {queryParamsHandling: 'preserve'})
    Router->>Router: compareNavigationGuard が compare/plots へ振り替える
    Store-->>EC: selectTableCompareView → 'plots'
    Store-->>EC: selectMetricVariantForView が compareMetricVariantsPlots を返す
    EC->>Header: [metricVariants] [tableCols] が plots 用に入れ替わる
```

## 図3: URL 直開きのときの整合

```mermaid
sequenceDiagram
    autonumber
    participant Router
    participant EC as ExperimentsComponent
    participant Store

    Router-->>EC: /tasks/compare/scalars（ids=a,b 付き）で起動
    EC->>EC: selectExperimentFromUrl() の combineLatest が発火
    EC->>EC: getTableModeFromURL() === 'compare'
    alt checkedExperiments が空で初回
        EC->>Store: dispatch getSelectedExperiments({ids: ['a','b']})
        Note right of Store: Store とリストに無ければ tasks.get_all_ex で取り直す
    end
    alt Store の tableMode と URL が食い違う
        EC->>EC: modeChanged(getTableModeFromURL())
    end
    EC->>Store: dispatch setTableMode({mode: tableMode()})
```
