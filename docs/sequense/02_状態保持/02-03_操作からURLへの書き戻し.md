# 02-03 操作から URL への書き戻し

URL に載る値（列構成・ソート・フィルタ・アーカイブ・deep）は、
必ず `setURLParams` という共通の Action を経由して書き込まれる。
書き込む側は 3 通りあり、どれも最後は `RouterEffects.setTableParams` に合流する。

## 図1: ソート変更

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent
    participant Store
    participant ViewEff as ViewEffects
    participant RouterEff as RouterEffects

    User->>SmTable: 列ヘッダをクリック（Shift 併用で複数ソート）
    SmTable->>ExpTable: sortChanged.emit({isShift, field})
    ExpTable->>ExpTable: onSortChanged() → scrollTableToTop()
    ExpTable->>EC: sortedChanged.emit({isShift, colId})
    EC->>Store: dispatch tableSortChanged({isShift, colId})

    Store->>ViewEff: tableSortChange effect
    ViewEff->>Store: select(selectTableSortFields)（現在のソート配列）
    ViewEff->>ViewEff: addMultipleSortColumns(oldOrders, colId, isShift)
    ViewEff->>Store: dispatch setURLParams({orders, update: true})
    Store->>RouterEff: setTableParams effect
    RouterEff->>RouterEff: encodeOrder(orders)
    RouterEff-->>User: navigate([], {queryParams: {order: '...'}})
    Note over RouterEff,Store: Store の projectColumnsSortOrder は<br/>URL 経由で setTableSort が来たときに更新される（02-02）
```

## 図2: 列構成の変更

```mermaid
sequenceDiagram
    autonumber
    participant EC as ExperimentsComponent
    participant Store
    participant ViewEff as ViewEffects
    participant RouterEff as RouterEffects

    alt 列の表示切替
        EC->>Store: dispatch toggleColHidden({columnId, projectId})
    else 列の追加・削除・並べ替え
        EC->>Store: dispatch addColumn / removeCol / setColsOrderForProject
        EC->>Store: dispatch updateUrlParams()
    end

    Store->>ViewEff: setURLParams effect（ofType: updateUrlParams, toggleColHidden）
    ViewEff->>Store: cols / hiddenCols / metricsCols / colsOrder / isDeep / sortFields / filters を読む
    ViewEff->>ViewEff: encodeColumns(cols, hiddenCols, metricsCols[projectId], colsOrder)
    ViewEff->>Store: dispatch setURLParams({columns, filters, orders, isDeep, update: true})
    Store->>RouterEff: setTableParams effect
    RouterEff-->>RouterEff: navigate([], {queryParams: {columns, order, filter, deep}})
```

`toggleColHidden` だけは `updateUrlParams` を挟まず、直接 `setURLParams` effect の対象になっている。
一方 `addColumn` や `removeCol` は、呼び出し側が明示的に `updateUrlParams()` を続けて発行する必要がある。

## 図3: RouterEffects が組み立てるクエリ

```mermaid
sequenceDiagram
    autonumber
    participant Store
    participant RouterEff as RouterEffects
    participant Router

    Store->>RouterEff: setURLParams({columns?, orders?, filters?, isArchived?, isDeep?, update?, others?})
    RouterEff->>RouterEff: firstUpdate = !route.snapshot.queryParams.order
    RouterEff->>RouterEff: columns → uniq(columns)
    RouterEff->>RouterEff: orders → encodeOrder()
    RouterEff->>RouterEff: filters → encodeFilters() ／ 空なら null（=クエリから消す）
    RouterEff->>RouterEff: isArchived → 'true' または null
    RouterEff->>Router: navigate([], {queryParamsHandling: update ? 'merge' : undefined,<br/>replaceUrl: firstUpdate})
```

`queryParamsHandling: 'merge'` なので、指定しなかったパラメータは消えずに残る。
値を消したいときは `undefined` ではなく `null` を入れる必要があり、
フィルタ全消し（`clearTableFiltersHandler`）や検索クリア（`others: {q: null}`）はこの形を使っている。
