# 03-05 ヘッダーへのテンプレート注入

ヘッダーには 2 種類のテンプレート注入がある。
`ExperimentsComponent` から降りてくるもの（NEW TASK ボタン）と、
ヘッダー自身が孫コンポーネントへ渡すもの（カスタム列メニューの中身）である。

## 図1: NEW TASK ボタン（親 → 子）

```mermaid
sequenceDiagram
    autonumber
    participant EC as ExperimentsComponent
    participant Header as sm-experiment-header
    participant Media as BreakpointObserver
    participant Dialog as CreateExperimentDialogComponent
    participant Store

    EC->>Header: addButtonTemplate に addButton を渡す
    Header->>Media: isSmallScreen$ を購読
    Media-->>Header: {matches: true/false}
    Header->>Header: ngTemplateOutlet で addButtonTemplate() を描画<br/>context の smallScreen に matches を渡す

    Note over EC: テンプレート側は let-isSmallScreen="smallScreen" で受ける
    EC->>EC: selectedProjectId !== '*' のときだけボタンを描く
    EC->>EC: disabled は inArchivedMode() または exampleProject()
    EC->>EC: isSmallScreen ならラベルを省いてアイコンだけにする

    Note over EC,Dialog: クリック時
    EC->>Dialog: dialog.open(CreateExperimentDialogComponent, {width: '800px'})
    Dialog-->>EC: afterClosed() → data
    EC->>Store: dispatch createExperiment({data})
```

ヘッダーは画面幅だけを提供し、ボタンを出すかどうか・押されたら何をするかは
`ExperimentsComponent` が持つ。ヘッダーに `newExperiment` の `output` を足さずに済んでいる。

## 図2: カスタム列メニュー（子 → 孫）

```mermaid
sequenceDiagram
    autonumber
    participant Header as sm-experiment-header
    participant ColsMenu as sm-custom-cols-menu
    participant MetricSel as sm-select-metric-for-custom-col
    participant EC as ExperimentsComponent

    Note over Header: metricsTemplate と hyperParamsTemplate を宣言
    Header->>ColsMenu: sections に 2 要素を渡す<br/>{title:'add metric', name:'metrics', options: metricVariants(), template: metricsTemplate}<br/>{name:'hyperparameters', options: hyperParams(), template: hyperParamsTemplate}
    Note right of ColsMenu: TemplateRef を設定オブジェクトのプロパティとして渡す

    ColsMenu->>ColsMenu: メニュー内で「ADD CUSTOM COLUMN」の選択肢を出す
    ColsMenu->>MetricSel: ngTemplateOutlet で sections()[0].template を描画<br/>context の $implicit は sections()[0]
    Note over Header,MetricSel: テンプレート側は let-sectionData で受け、<br/>sectionData.options を子に渡す

    MetricSel->>Header: selectedMetricToShow.emit(event)
    Header->>EC: (selectedMetricToShow)
    Note right of EC: 01-03 の列追加フローへ
```

比較モードのときは `sections` が 1 要素だけになり、
ハイパーパラメータのセクションが消える。
`sm-custom-cols-menu` 側は配列の長さを見てタブ表示を切り替えるだけで、
どのコンポーネントが入るかは知らない。
