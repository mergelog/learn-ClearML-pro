# 05-04 列ヘッダーまでの経路

列名・ソート矢印・フィルタ漏斗が並ぶ `th` の中身まで。

セル（05-03）と同じ「渡して、呼び戻される」形だが、**`th` は列の種類で3通りに分岐する**。

## 図1: th の中身が決まるまで

```mermaid
sequenceDiagram
    autonumber
    participant ExpTable as sm-experiments-table
    participant SmTable as sm-table
    participant PTable as p-table
    participant FilterSort as sm-table-filter-sort

    ExpTable->>SmTable: pTemplate="sort-filter" と pTemplate="checkbox" を渡す
    SmTable->>SmTable: ngAfterContentInit → sortFilterTemplate / checkboxTemplate

    PTable->>SmTable: ng-template #header を呼ぶ
    SmTable->>SmTable: visibleColumns() を回して th を作る<br/>pReorderableColumn / smResizableColumn を付ける
    SmTable->>SmTable: @switch (col.headerType)

    alt headerType = sortFilter
        SmTable->>ExpTable: ngTemplateOutlet sortFilterTemplate（context: col）
        ExpTable->>FilterSort: [column]=col [value]=filtersValues()[col.id]<br/>[options]=filtersOptions()[col.id] [sortOrder]=tableSortFieldsObject()[col.id]
    else headerType = checkBox
        SmTable->>ExpTable: ngTemplateOutlet checkboxTemplate
        Note right of ExpTable: 全選択チェックボックス + ドロップダウン（05-12）
    else それ以外
        SmTable->>SmTable: col.header をそのまま表示（+ 説明ツールチップ）
    end
```

`th` に付く2つのディレクティブが、並べ替えと幅変更の入口になる（05-15）。
`col.disableDrag` の列（チェックボックス列など）は両方とも無効化される。

## 図2: sm-table-filter-sort の中

```mermaid
sequenceDiagram
    autonumber
    participant FilterSort as sm-table-filter-sort
    participant Menu as sm-menu
    participant List as sm-checkbox-three-state-list
    participant Duration as sm-table-filter-duration 系

    FilterSort->>FilterSort: column().sortable ならソートボタン
    FilterSort->>FilterSort: column().filterable なら列名 + sm-menu
    FilterSort->>Menu: [enableSearch]=column().searchableFilter
    Menu->>FilterSort: @switch (column().filterType)
    FilterSort->>Duration: duration / durationNumeric / durationDate 列
    FilterSort->>List: @default（値のチェックリスト）
    FilterSort->>List: [options]=paginatedOptions() [checkedList]=value()
    Note over FilterSort,List: paginatedOptions は<br/>pinned（開いた瞬間の選択値）を先頭に固定して<br/>pageSize × pageNumber 件だけ切り出す computed
```

この部品は**選択肢のページングと検索の状態を自分の signal で持つ**唯一のテーブル部品。
`pageNumber` `loading` `searching` `pinnedValues` `lengthBeforeLoad` はすべてローカル。
Store に出すのは「値が確定したフィルタ」と「サーバ検索が必要な語」だけ（05-14）。

## 状態の要点

- 列定義 `tableCols` は Store（サーバのユーザープリファレンス + URL の `columns`）が原本。
- ソート状態は Store の `tableSortFields`（原本は URL の `order`）を
  `tableSortFieldsObject()` で `{列ID: {index, order}}` に変換して1列ぶんだけ渡す。
- フィルタの選択値は Store の `tableFilters`（原本は URL の `filter`）を
  `filtersValues()` で列 ID 別にほどいて渡す。
- 選択肢（`filtersOptions()`）はユーザー一覧・タグ・親タスクなど別々の Store 断片を
  1つの `computed` で組み立てている。
