# 05-17 右クリックメニュー

メニュー部品そのものの住所は 05-08。ここでは**開き方が3通りある**ことと、その違いを追う。

## 図1: 行を右クリック

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Tr as tr（pContextMenuRow）
    participant PTable as p-table
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    User->>Tr: 右クリック
    Note right of Tr: pContextMenuRowDisabled = !rowRightClick.observed<br/>親が購読していなければ何も起きない
    Tr->>PTable: コンテキストメニュー選択
    PTable->>SmTable: (onContextMenuSelect)
    SmTable->>SmTable: openContext() → rightClicked = true<br/>contextMenuSelection = null で p-table 側の選択を取り消す
    SmTable->>SmTable: setTimeout(() => menu().hide())（PrimeNG のメニューは使わない）
    SmTable->>ExpTable: (rowRightClick) {e, rowData, single: undefined}
    ExpTable->>ExpTable: contextExperiment.set(該当タスク)
    alt その行が未チェック
        ExpTable->>EC: (experimentsSelectionChanged) [その行] で置換
        Note right of ExpTable: prevSelected も更新しておく（Shift 選択の起点）
    end
    ExpTable->>EC: (contextMenu) {x: clientX, y: clientY}
    EC->>EC: onContextMenuOpen() → contextMenu().openMenu({x, y})
```

`p-context-menu` は DOM 上に置いてあるが `class="d-none"` で、開いても即 `hide()` される。
**PrimeNG のメニューは座標取得のためだけに使い、実際の描画は Angular Material の
`MatMenuTrigger`**（`sm-experiment-menu-extended` 側）が行う。

## 図2: 行末の3点ボタン

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Btn as 3点ボタン（行の右端）
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    User->>Btn: クリック
    Btn->>SmTable: $event.stopPropagation()（行クリックを止める）
    Btn->>SmTable: openContext({originalEvent, data: rowData, single: true})
    SmTable->>ExpTable: (rowRightClick) {single: true}
    ExpTable->>ExpTable: single なので contextExperiment.set(rowData) だけ<br/>選択は一切変更しない
    ExpTable->>EC: (contextMenu) {single: true}
    EC->>EC: singleRowContext = true
    Note over EC: メニューの [selectedExperiments] が<br/>「チェック済み全件」から「この1件」に切り替わる
```

`single` の違いがメニューの対象範囲を決める。

EC 側は `single` をそのまま `singleRowContext` に入れ、メニューの input を切り替える。

| `singleRowContext` | selectedExperiments | numSelected | useCurrentEntity |
| --- | --- | --- | --- |
| `true`（3点ボタン） | 選択中の1件（または無し） | 1 | true |
| falsy（右クリック / 左クリック） | `checkedExperiments` 全件 | 件数 | false |

## 図3: チェック済みの行を左クリック

すでにチェックが入っている行を普通にクリックしたときも開く。

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    User->>SmTable: チェック済みの行を左クリック
    SmTable->>ExpTable: (rowClicked)（250ms 判定の後）
    ExpTable->>ExpTable: tableRowClicked() → checkedExperiments に含まれる
    ExpTable->>ExpTable: openContextMenu({e, rowData, backdrop: true})
    ExpTable->>EC: (contextMenu) {backdrop: true}
    EC->>EC: menuBackdrop = true → メニューに [backdrop] で渡す
    Note over ExpTable,EC: backdrop 付きは「選択の一括操作を促す」表示。<br/>複数選択中に見失わないよう背景を落とす
```

## 閉じるとき

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Menu as sm-experiment-menu-extended
    participant EC as ExperimentsComponent

    User->>Menu: メニュー外をクリック
    Menu->>Menu: @HostListener('document:click') → 自分の中でなければ closeMenu()
    Menu->>EC: (menuClosed)
    EC->>EC: setContextMenuStatus(false)
    Note over Menu,EC: contextMenuActive が false に戻り、<br/>行のハイライト（context-menu-opened）が外れる
```
