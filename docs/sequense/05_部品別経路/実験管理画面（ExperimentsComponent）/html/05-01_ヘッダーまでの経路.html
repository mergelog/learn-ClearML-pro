05-01 ヘッダーまでの経路

画面上端の帯（アーカイブ切替、Table/Details/Compare 切替、検索、CSV、列追加、更新）まで。

sm-experiment-header は EC のテンプレート直下にいる、ただの表示部品。 Store を一切見ず、全部 input で受け取り、全部 output で返す。 例外はカスタム列メニューの開閉状態（customColumnMode）だけで、これはヘッダー内のローカル状態。

    EC->>Header: [tableCols] [isArchived] [tableFilters] [tableMode]<br/>[metricVariants] [hyperParams] [noData] ... すべて Store 由来
    EC->>Header: [addButtonTemplate]=addButton（EC 側の ng-template）

    Header->>Archive: [showArchived]=isArchived()
    Header->>Toggle: [options]=toggleButtons() / [ngModel]=tableMode()
    Header->>Search: （子が自分で Store を見る例外部品）
    Header->>Clear: [tableFilters]=tableFilters()
    Header->>Cols: [sections] [tableCols] [isLoading]
    Header->>Refresh: [allowAutoRefresh]=true
    Note over Header,Cols: NEW TASK ボタンだけは EC の ng-template を<br/>ngTemplateOutlet で描く（03-05 参照）

図2: ヘッダーの操作が EC へ戻るまで

ヘッダーは状態を持たないので、押されたら即 output で親に投げる。

sequenceDiagram
    autonumber
    participant User
    participant Header as sm-experiment-header
    participant EC as ExperimentsComponent
    participant Store as NgRx Store

    User->>Header: アーカイブ切替
    Header->>EC: (isArchivedChanged)
    EC->>EC: archivedChanged() → 確認ダイアログ → closePanel()
    Note right of EC: URL の archive=true を書き換える<br/>（URL が原本）

    User->>Header: Table / Details / Compare
    Header->>EC: (tableModeChanged)
    EC->>Store: dispatch setTableMode + ルーティング

    User->>Header: 列を追加・除去
    Header->>EC: (selectedMetricToShow) / (removeColFromList)
    EC->>Store: dispatch addColumn / removeCol → updateUrlParams

    User->>Header: CSV ダウンロード
    Header->>EC: (downloadTableAsCSV)
    EC->>EC: table().table().downloadTableAsCSV()（05-20）

    User->>Header: 更新ボタン
    Header->>EC: (setAutoRefresh)
    EC->>Store: dispatch setAutoRefresh

tableMode の判定だけは注意が必要。テンプレート側で getTableModeFromURL() を呼んで Store ではなく URL を直接見ている箇所がある（比較モードとテーブルモードで同じ output の 処理先を振り分けるため）。Store の tableMode() は遷移途中で古い値のことがある。

読みどころ

  • ヘッダー呼び出し: experiments.component.html:2
  • NEW TASK テンプレート: experiments.component.html:33
  • ヘッダーのテンプレート: experiment-header.component.html
  • URL を直接読む判定: experiments.component.ts:523
