05-05 カードビューまでの経路

情報パネルを開くとテーブルが左に縮み、行がカードに変わる。その切り替わりと、カードの中身まで。

同じ p-table を使い続けていて、minimizedView という1つの入力で 列の羅列（td × 列数）を1枚のカード（td × 1）に差し替えている。

図1: 縮小表示に切り替わるまで

sequenceDiagram
    autonumber
    participant Store as NgRx Store
    participant EC as ExperimentsComponent
    participant ExpTable as sm-experiments-table
    participant SmTable as sm-table
    participant PTable as p-table

    Note over Store,EC: minimizedView は URL 由来<br/>selectMinimizedView = ルートパラメータに experimentId か ids があるか
    Store-->>EC: minimizedView()
    EC->>ExpTable: [minimizedView]=minimizedView() [cardHeight]=112<br/>[cardsCollapsed]=cardsCollapsed() [showColors]=showColorsInCards()
    ExpTable->>SmTable: [minimizedView] をそのまま流す
    SmTable->>PTable: class card-view / [virtualScrollItemSize]=cardHeight()
    SmTable->>SmTable: table() が生えたとき gotTable() → updateFilter()<br/>minimizedView なら p-table の _filter と sortSingle を差し替え
    Note right of SmTable: データ更新でページ位置が 0 に戻るのを防ぐための上書き
    SmTable->>SmTable: calcResize() → 幅は「1列ぶん」として再計算

minimizedView が URL 由来なのが重要。情報パネルを開く＝URL に experimentId が載る＝ テーブルが縮む、という一本道になっていて、パネルの開閉状態をどこかに別途持っていない。

図2: カード1枚の中身

sequenceDiagram
    autonumber
    participant PTable as p-table
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant Card as sm-table-card

    PTable->>SmTable: #body（行テンプレート）
    SmTable->>SmTable: minimizedView なので td を1個だけ作る
    SmTable->>ExpTable: ngTemplateOutlet cardTemplate<br/>context: rowData, rowNumber, selected
    ExpTable->>Card: [cardName] [columns] [rowData] [checked]<br/>[tagsTemplate]=tagList [compactColDataTemplate]=compactCol
    ExpTable->>Card: ng-content で差し込む部品を並べる
    Note over ExpTable,Card: sm-table-card は ng-content select= で<br/>mat-checkbox / sm-status-icon-label / [sm-name-icon] /<br/>[sm-name-version] / [sm-mini-tags] を所定の位置に置く
    Card->>Card: tagsTemplate と compactColDataTemplate は<br/>ngTemplateOutlet で自分の好きな場所に描く

カードは「input で渡す」「ng-content で差し込む」「ng-template を渡す」の3方式が同時に使われている 珍しい例。細かい使い分けは 03-04 を参照。

図3: カード表示時のヘッダー

縮小表示では列ヘッダーが1本の帯になり、そこにフィルタとソートが集まる。
