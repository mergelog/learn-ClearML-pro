05-07 フッターまでの経路

2件以上チェックしたときに下から出てくる一括操作バーまで。

sm-entity-footer は常にテンプレートに存在する。出入りしているのは CSS クラスだけで、 footerState$ が値を流し始めるかどうかが実質のスイッチになっている。

図1: フッターが現れるまで

sequenceDiagram
    autonumber
    participant Store as NgRx Store
    participant Base as BaseEntityPageComponent
    participant EC as ExperimentsComponent
    participant Footer as sm-entity-footer

    EC->>EC: createFooterItemsRunner()（コンストラクタ）
    EC->>Base: createFooterItems({selected$, data$, tags$, ...})
    Base->>Base: createFooterState() で6本の Observable を combineLatest
    Note right of Base: debounceTime(100)<br/>filter(選択が2件以上 or 直前が2件以上 or showAll)
    Base-->>EC: footerState$

    Store-->>EC: checkedExperiments$ が2件以上になる
    Base-->>Footer: [footerState] に初めて値が届く
    EC->>Footer: [footerItems]=footerItems（ボタン定義の配列）
    EC->>Footer: class.footer-visible を付ける

footerItems は ShowItemsFooterSelected / ArchiveFooterItem などのクラスの配列で、 EC のコンストラクタで一度組み立てるだけ（Store には入れない）。 どのボタンを押せるかは footerState.data（Store の selectedExperimentsDisableAvailable）が決める。

図2: フッターのボタンが押されたとき

sequenceDiagram
    autonumber
    participant User
    participant Footer as sm-entity-footer
    participant EC as ExperimentsComponent
    participant Menu as sm-experiment-menu-extended
    participant Store as NgRx Store

    User->>Footer: Archive などを押す
    Footer->>EC: (footerItemClick) {item, emitValue}
    EC->>EC: onFooterHandler() → singleRowContext = false
    EC->>EC: switch (item.id)
    EC->>Menu: contextMenu().restoreArchive() など<br/>（コンテキストメニューの処理を呼び直す）
    Menu->>Store: dispatch（確認ダイアログを経て一括操作の Action）
    Note over EC,Menu: フッターは自分で Action を作らない。<br/>右クリックメニューと同じ処理に合流させている

同じ操作を「右クリック」と「フッター」の2箇所から起動できるため、処理の実体は コンテキストメニュー側に1つだけ置き、フッターはそれを呼ぶという作りになっている。 singleRowContext フラグが「1行だけが対象か、チェックした全件が対象か」を切り替える。

タグ追加だけは例外で、フッターから直接 tagSelected → BaseEntityPageComponent.tagSelected() → addTag を dispatch する。

状態の要点

  • 表示条件: checkedExperiments（Store）が2件以上、または「選択のみ表示」が有効。
  • ボタン定義: EC のプロパティ（footerItems）。モード切替時に modeChanged() から作り直す。
  • 各ボタンの活性: Store の selectedExperimentsDisableAvailable。 これは setSelectedExperiments の effect が選択内容から毎回計算して Store に戻している。
