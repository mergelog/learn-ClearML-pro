05-19 カードビューの操作

縮小表示（カード）では、テーブル表示と同じ操作でも経路が変わる。到達経路は 05-05、ここは操作。

図1: カードを選ぶ

テーブル表示と違い、tr の click は塞がれている。

sequenceDiagram
    autonumber
    participant User
    participant Tr as tr（pSelectableRow）
    participant PTable as p-table
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent
    participant Store as NgRx Store

    Note over Tr,SmTable: (click) は !minimizedView() 条件付きなので<br/>カード表示では checkClick を通らない
    User->>Tr: カードをクリック
    Tr->>PTable: pSelectableRow の選択
    PTable->>SmTable: (onRowSelect)
    SmTable->>ExpTable: (rowSelectionChanged)
    ExpTable->>EC: (experimentSelectionChanged) {origin: 'table'}
    EC->>Store: minimizedView() なので dispatch experimentSelectionChanged
    Note over EC,Store: URL の :experimentId が変わり、<br/>右ペインの情報パネルが差し替わる

選択解除の向きも p-table 経由。カード表示では onRowDeselected が data: null を返すので、 同じカードを押し直すと選択が外れる。

図2: 選択中のカードをもう一度押す

sequenceDiagram
    autonumber
    participant User
    participant Card as sm-table-card
    participant BaseTable as BaseTableView
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    Note over Card: click は selected のときだけ cardClicked を呼ぶ<br/>つまり選択中のカードしか反応しない
    User->>Card: 1回目のクリック
    Card->>BaseTable: cardClicked()
    BaseTable->>BaseTable: clickDelayHandle に 250ms のタイマー

    alt 250ms 以内に2回目
        User->>Card: 2回目
        BaseTable->>BaseTable: タイマー破棄
        BaseTable->>EC: (closePanel)
        EC->>EC: closePanel() → setTableMode('table') + URL から id を落とす
    else 来なかった
        BaseTable->>ExpTable: openContextMenu({e, rowData, backdrop: true})
        ExpTable->>EC: (contextMenu) {backdrop: true}
    end

「選択中のカードをシングルクリック → メニュー」「ダブルクリック → パネルを閉じる」という 割り当てになっている。テーブル表示の 250ms 判定（05-11）とは別実装で、 BaseTableView.cardClicked() 側に置かれている。

図3: 折りたたみ

sequenceDiagram
    autonumber
    participant User
    participant Header as カードヘッダーの折りたたみボタン
    participant SmTable as sm-table
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent
    participant Store as NgRx Store

    User->>Header: クリック
    Header->>SmTable: (cardsCollapsedToggle)
    SmTable->>ExpTable: (cardsCollapsedChanged)
    ExpTable->>EC: そのまま素通し
    EC->>EC: cardsCollapsedToggle()（基底クラス）
    EC->>Store: dispatch toggleCardsCollapsed({entityType})
    Store-->>EC: cardsCollapsed() が反転
    EC->>SmTable: [cardsCollapsed] → カード高さを 48px に、タグを mini 表示に
    Note over Store,EC: 保存先は core の view state（エンティティ種別ごと）。<br/>URL には出ない

図4: カード表示のフィルタ

列ヘッダーが無いので、1つのメニューに全列のフィルタが入れ子で入る。

sequenceDiagram
    autonumber
    participant User
    participant CardFilter as sm-table-card-filter
    participant BaseTable as BaseTableView
    participant ExpTable as sm-experiments-table
    participant EC as ExperimentsComponent

    User->>CardFilter: 漏斗 → 列名 → サブメニュー
    CardFilter->>ExpTable: (menuOpened) col
    ExpTable->>ExpTable: columnFilterOpened(col)（05-14 図1 と同じ）
    User->>CardFilter: 値をチェック
    CardFilter->>ExpTable: (filterChanged) {col: 列ID, value}
    ExpTable->>BaseTable: tableFilterChanged({id: $event.col}, $event)
    Note right of ExpTable: 列オブジェクトではなく {id} だけを渡す<br/>（メニューが持っているのは列 ID だけ）
    BaseTable->>EC: (filterChanged) → 以降は 05-14 と同じ
    User->>CardFilter: Clear all
    CardFilter->>EC: (clearAll) → (clearTableFilters)

タグのシステムタグだけは別扱いで、(subFilterChanged) から tableFilterChanged({id: 'system_tags'}, ...) として投げられる。
