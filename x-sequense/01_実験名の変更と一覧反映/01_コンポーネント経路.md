# 01 コンポーネント経路

名前を入力する `sm-inline-edit` と、新しい名前を表示する `sm-table-card` は、どちらも `ExperimentsComponent` の配下にある。
ただし入力側は `router-outlet` 経由、表示側はテンプレート直書きで、経路が違う。

```text
ExperimentsComponent
├─ as-split-area（左）
│   └─ sm-experiments-table
│       └─ sm-table
│           └─ p-table
│               └─ 各行: cardTemplate → sm-table-card      ← 新しい名前が出る
└─ as-split-area（右）
    └─ router-outlet（:experimentId）
        └─ sm-experiment-output
            └─ sm-experiment-info-header
                └─ sm-inline-edit                          ← 名前を入力する
```

## 図1: 入力欄までの経路

```mermaid
sequenceDiagram
    autonumber
    participant Router as Angular Router
    participant EC as ExperimentsComponent
    participant Outlet as router-outlet（右ペイン）
    participant Output as sm-experiment-output
    participant InfoHeader as sm-experiment-info-header
    participant Inline as sm-inline-edit

    Router->>EC: path '' の loadComponent
    EC->>Outlet: 右の as-split-area に router-outlet を置く
    Router->>Outlet: ':experimentId' の loadComponent
    Outlet->>Output: ExperimentOutputComponent を生成
    Output->>InfoHeader: [experiment]="selectedExperiment()"<br/>[infoData]="infoData$ | ngrxPush"<br/>[editable]="!isExample"
    InfoHeader->>Inline: [originalText]="infoData()?.name || experiment()?.name"<br/>[editable]="editable()" [minLength]="2" [required]="true"
    InfoHeader->>Inline: ng-content に {{experiment()?.name}} の span を投影
    Note over Inline: 通常時は投影された名前を表示し、<br/>edit-mode のときだけ入力欄を表示する
```

- `isExample` は `isReadOnly(selectedExperiment())` の結果。サンプル実験は編集できない。
- 入力欄の初期値 `originalText` は `infoData` の名前を優先する。表示用の span は `experiment()`（`info.selectedExperiment`）の名前を使う。二つの出どころは [02](./02_状態経路.md) で扱う。

## 図2: 一覧カードまでの経路

```mermaid
sequenceDiagram
    autonumber
    participant EC as ExperimentsComponent
    participant ExpTable as sm-experiments-table
    participant SmTable as sm-table
    participant PTable as p-table
    participant Card as sm-table-card

    EC->>ExpTable: [experiments]="$any(experiments$ | ngrxPush)"<br/>[minimizedView]="minimizedView()"
    ExpTable->>SmTable: [tableData]="experiments()"<br/>[minimizedView]="minimizedView()"
    ExpTable->>SmTable: ng-template pTemplate="card" を投影
    SmTable->>SmTable: ngAfterContentInit で templates() から<br/>cardTemplate を取り出す
    SmTable->>PTable: [value]="tableData()"
    PTable->>SmTable: 行ごとに SmTable 定義の body テンプレートを展開
    alt minimizedView() が true（詳細パネル表示中）
        SmTable->>Card: ngTemplateOutlet="cardTemplate"<br/>context: {rowData, selected}
        Note over Card: テンプレートの持ち主は ExpTable。<br/>[cardName]="experiment.name" [rowData]="experiment"
        Card->>Card: {{cardName()}} を描画
    else false（一覧のみ）
        SmTable->>SmTable: 列ごとの td を描画（この資料の対象外）
    end
```

- `minimizedView()` は `selectMinimizedView` から来る Signal。URL パラメータに `experimentId` があれば true。
- カードのテンプレートは ExpTable が書き、SmTable が実体化する。ExpTable は `experiment.name` を直接 `cardName` に渡すだけで、名前を加工しない。

## 図3: 名前が確定したときの通知経路

```mermaid
sequenceDiagram
    autonumber
    participant Inline as sm-inline-edit
    participant InfoHeader as sm-experiment-info-header
    participant Output as sm-experiment-output
    participant Store as NgRx Store

    Inline->>InfoHeader: (textChanged) → onNameChanged(name)
    InfoHeader->>Output: (experimentNameChanged) → updateExperimentName(name)
    Output->>Store: dispatch experimentDetailsUpdated
    Note over Output,Store: コンポーネント間の線はここで切れる。<br/>一覧側へは Store 経由で届く（02 / 03-02）

    Inline->>InfoHeader: (inlineActiveStateChanged) → editExperimentName(edit)
    InfoHeader->>Store: dispatch activateEdit / deactivateEdit
    Note over InfoHeader,Store: 編集状態の通知は親へ上げず、<br/>InfoHeader が自分で dispatch する
```
