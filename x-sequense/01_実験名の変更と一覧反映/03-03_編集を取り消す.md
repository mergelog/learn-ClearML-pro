# 03-03 編集を取り消す

入力を保存せずに編集モードを閉じる操作。どの入口も最後は `inlineCanceled()` に集まり、API は呼ばない。

## 図1: 取り消しの入口

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Doc as document
    participant Inline as sm-inline-edit

    alt Esc キー
        User->>Inline: (keydown.escape)
        Inline->>Inline: inlineCanceled()
    else ×ボタン
        User->>Inline: (click) → $event.stopPropagation()
        Inline->>Inline: cancelClicked($event)
        Inline->>Inline: cancelClick.emit(event)（InfoHeader は購読していない）
        Inline->>Inline: inlineCanceled()
    else 外側をクリック
        User->>Doc: click
        Doc->>Inline: host の (document:click) → stopEditing()
        Inline->>Inline: active() が true なら inlineCanceled()
    else 値を変えずに確定
        User->>Inline: Enter / Tab / ✓
        Inline->>Inline: inlineSaved()
        Inline->>Inline: 値が originalText() と同じ → inlineCanceled()
    else コンポーネントの破棄
        Inline->>Inline: DestroyRef.onDestroy → stopEditing()
    end
```

- Inline の内側をクリックしても取り消されない。一番外側の div が `(click)="active() && $event.stopPropagation()"` で、編集中のクリックを `document` へ届かせない。

## 図2: inlineCanceled() の中身

```mermaid
sequenceDiagram
    autonumber
    participant Inline as sm-inline-edit
    participant InfoHeader as sm-experiment-info-header
    participant Store as NgRx Store（info）

    Inline->>Inline: inlineValue.set(originalText())
    Inline->>Inline: active.set(false)
    Inline->>InfoHeader: inlineActiveStateChanged.emit(false)
    InfoHeader->>Store: dispatch deactivateEdit
    Store->>Store: activeSectionEdit = false<br/>currentActiveSectionEdit = null
    Inline->>Inline: cancelEdit.emit()（InfoHeader は購読していない）
```

## 状態の要点

- 変わるのは Inline の `active` / `inlineValue` と、Store の編集中フラグだけ。`infoData` と一覧の `view.experiments` には触れない。
- `deactivateEdit` で `activeSectionEdit` が false に戻り、詳細の自動再取得が再開する。
