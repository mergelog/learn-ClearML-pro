# mp20260926 一時データセット投入

## 目的

`Semiconductor Quality Prediction` とは別に、`mp20260926` という名前のClearMLプロジェクトへ
データセットを1バージョンだけ登録したいための一時検証用スクリプト。

- 通常の `corepack pnpm seed:semiconductor:dataset` はDatasetを2バージョン
  （`1.0.0`, `2.0.0`）登録するが、これはそのうちの `1.0.0`（1,200行）だけを登録する。
- プロジェクト名 `mp20260926` はコード側にハードコードしてある
  （[tools/mp20260926_seed.py](tools/mp20260926_seed.py)）。

## 実行方法

前提: ClearML Serverが起動していること、`corepack pnpm py:setup` 実行済みであること。

```bash
scripts/clearml-run.sh .venv/bin/python -m tools.mp20260926_seed
```

## 登録される内容

| 項目 | 値 |
| --- | --- |
| プロジェクト | `mp20260926` |
| データセット名 | `semiconductor-quality-data` |
| バージョン | `1.0.0`（親Datasetなし） |
| 行数 | 1,200 |

同じコマンドを再実行しても、同じVersionが既に完了済みなら再登録しない
（`tools/semiconductor_seed`のensure_dataset相当の重複チェックを流用）。

生成元CSVの出力先: `.generated/semiconductor/mp20260926/`（Git管理対象外）。

## 後片付け

一時的な検証が終わったら削除してよいもの。

- コード: [tools/mp20260926_seed.py](tools/mp20260926_seed.py)
- 設定: [pyproject.toml](pyproject.toml) の `[tool.ruff.lint.per-file-ignores]` にある
  `"tools/mp20260926_seed.py" = ["T20"]` の1行
- このファイル自体
- ClearML Web上の `mp20260926` プロジェクトとDataset

### ClearML側の削除手順

Datasetは `mp20260926/.datasets/semiconductor-quality-data` という隠しサブプロジェクト配下に
実体（Task＋アップロード済みファイル）を持つ。そのため **プロジェクトをいきなり削除しようとすると
次のエラーで拒否される**。

```
Can't delete dataset
Project has associated non-empty datasets (please delete all the dataset versions or use force=true): id=...
```

正しい順序は次のとおり。

1. 先にDataset本体を削除する（Web UIの「Datasets」ビューから対象を選んで削除するか、
   下記のSDKコマンドで削除する）。

   ```bash
   scripts/clearml-run.sh .venv/bin/python -c "
   from clearml import Dataset
   Dataset.delete(dataset_id='<登録時にログへ出力されたID>', force=True)
   "
   ```

2. Datasetが消えて `mp20260926` プロジェクトが空になったら、Web UIから通常どおり
   プロジェクトを削除する。
