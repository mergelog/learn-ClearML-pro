# 比較画面のアイコン操作に操作名がなく、支援技術で判別できない

| 項目 | 内容 |
|---|---|
| カテゴリー | 操作 |
| 不具合内容 | タスク・モデル比較の差分移動、比較対象の操作、凡例、パネル開閉などのアイコンボタンに accessible name がない |
| 期待動作 | すべてのアイコン操作が、対象と操作内容を含む一意の accessible name を持つ |
| 直さないと困ること | スクリーンリーダー利用者が「次の差分」「比較から除外」「このタスクのメニュー」「パネルを開閉」を区別できず、比較操作を完結できない |
| 修正規模 | 中 |

| 項目 | 内容 |
|---|---|
| 画面 | タスク比較・モデル比較（DETAILS、NETWORK / Hyperparameters、SCALARS など） |
| 観点 | J（操作性とアクセシビリティ） |
| 重大度 | S2 |
| 確度 | 再現済み（axe） |
| 由来 | 上流 |
| 発生条件 | スクリーンリーダー、音声操作、またはアクセシビリティツリーから比較画面を操作する場合 |
| 関連 | [29](./29_実験詳細のアイコンボタンに操作名がなく支援技術で判別できない.md)（詳細ヘッダー）、[32](./32_実験一覧の表で操作名と選択欄のラベルが不足している.md)（共通表） |

## 症状

実バックエンドでタスク比較の DETAILS を開き、`sm-experiments-compare` に axe 4.13.0 を実行した。critical の `button-name` 違反が検出され、代表例として次のボタンが空のボタンとして扱われる。

| 対象 | 本来の操作 |
|---|---|
| `previousDiffButton` / `nextDiffButton` | 前後の差分へ移動 |
| `dragAndDropButton` / `setBaselineButton` / `removeComparision` | 比較カードを並べ替える、基準にする、比較から外す |
| `closeLegend`（各比較対象のメニュー、凡例全体を閉じる） | 比較対象のメニューを開く、凡例を閉じる |
| `drawerExpandButton` | 比較カードのパネルを開閉する |
| `sm-refresh-button` | 比較データを更新する |

`smTooltip` の文言は hover 用であり、ボタンの accessible name にはならない。モデル比較も同じ比較シェル・差分移動部品を使うため、同種の問題が発生する。

## 再現手順

1. 2件以上のタスクを選んだ比較の DETAILS を開く
2. `npx playwright test -c x-不具合調査/scripts/playwright.config.ts p3-diff-models-compare.spec.ts --grep axe` を実行する
3. 出力の `compare` に `button-name` の critical 違反が出ることを確認する

## 原因

- [compare-card-list.component.html:30](../src/app/webapp-common/experiments-compare/dumbs/compare-card-list/compare-card-list.component.html#L30)・[同:35](../src/app/webapp-common/experiments-compare/dumbs/compare-card-list/compare-card-list.component.html#L35)・[同:40](../src/app/webapp-common/experiments-compare/dumbs/compare-card-list/compare-card-list.component.html#L40) はアイコンだけのボタンである
- [experiment-compare-details.component.html:119](../src/app/webapp-common/experiments-compare/containers/experiment-compare-details/experiment-compare-details.component.html#L119) と、モデル比較・パラメータ比較の対応テンプレートも `smTooltip` だけで `aria-label` を持たない
- [experiments-compare.component.html:34](../src/app/webapp-common/experiments-compare/experiments-compare.component.html#L34)・[同:48](../src/app/webapp-common/experiments-compare/experiments-compare.component.html#L48) のメニューと閉じるボタンにも操作名がない
- [drawer.component.html:6](../src/app/webapp-common/shared/ui-components/panel/drawer/drawer.component.html#L6) と [refresh-button.component.html:8](../src/app/webapp-common/shared/components/refresh-button/refresh-button.component.html#L8) は比較画面から使う共通ボタンだが、accessible name を受け取る仕組みがない

## 影響範囲と同種箇所

- `sm-compare-card-list`、`al-drawer`、`sm-refresh-button` は比較の複数タブで共用される
- `previousDiffButton` / `nextDiffButton` はタスク DETAILS・モデル DETAILS・パラメータ比較の3テンプレートに重複している
- モデル一覧の列操作・選択欄の違反は共通 table の問題として32に登録済みであり、本件には重複登録しない

## 対策案

共通ボタンに `ariaLabel` input を追加し、呼び出し側で「次の差分」「{タスク名}を比較から外す」「{タスク名}のメニュー」「比較パネルを開く」などを渡す。`smTooltip` は補助表示として残し、操作名の唯一の供給源にしない。差分移動テンプレートは共通コンポーネント化するか、3箇所すべてに同じラベルを付けて回帰を防ぐ。

## 検証範囲

- 確認したこと：Playwright（Chromium）で実バックエンドのタスク比較 DETAILS に axe を実行し、critical の `button-name` を確認した。モデル比較を含む主要な直接 URL 13件と戻る・進むも [scripts/p3-diff-models-compare.spec.ts](./scripts/p3-diff-models-compare.spec.ts) で確認した
- 確認していないこと：全比較タブ・実際のスクリーンリーダーでの読み上げ、比較対象が1件だけの場合
- 由来：対象ファイルは比較資料で実質差分に含まれない
