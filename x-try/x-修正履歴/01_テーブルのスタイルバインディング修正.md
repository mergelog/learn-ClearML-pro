# 01. テーブルのスタイルバインディング修正

- 日付: 2026-09-16
- 対象: `src/app/webapp-common/shared/ui-components/data/table/table.component.html`

## 修正一覧

| # | 行 | 内容 |
|---|---|---|
| 1 | 66 | ヘッダー `[style.max-width]` が `&&` で `false` を返し NG0318 が発生。三項に変更し `null` を返すようにした。値が消えず残る不具合も解消。 |
| 2 | 150 | ボディセル `[style.max-width]` も同じ式。同様に三項へ変更。セル生成ごとの `console.warn` がなくなる。 |
| 3 | 40 | `[style.top.px]="this.scrollable && ..."` が signal を呼んでおらず常に truthy。`scrollable() ? noDataTop : null` に修正。 |
| 4 | 46 | `noDataTemplate` へ渡す `noDataTop` も同じ式のため同様に修正。`this.` は不要なので削除。 |

## 補足

- NG0318 / NG02956 はいずれも dev モード限定の警告。本番ビルドでは出力されず、性能への影響もない。
- 挙動が変わるのは `scrollable` 未指定の `queue-task-table` のみ。0 件時の "No data to show" が縦中央から上端へ移動する。
- NG02956（NgOptimizedImage の preconnect 警告）は未対応。ローカル SVG のため実害なし。
