# 待ち時間の見せ方を揃える

| 項目 | 内容 |
| --- | --- |
| 分類 | UX体験 |
| 領域 | 自作（`features/data-catalog`・`features/quality-pipeline`）／一部は凍結領域の共有部品 |
| 直る体験 | 読み込み中に画面が何をしているか分かる。読み込みの前後で行がずれない |
| 規模 | 小〜中 |
| 状態 | 未着手 |

## いま画面で起きていること

自作画面の待ち時間は、すべて「Loading…」という1行の文字である。

| 場所 | 表示 |
| --- | --- |
| [catalog-assets-table.component.html:45](../src/app/features/data-catalog/components/catalog-assets-table/catalog-assets-table.component.html#L45) | 表の本体を `colspan=6` の1セルに置き換えて `Loading…` |
| [catalog-asset-detail-page.component.html:25](../src/app/features/data-catalog/containers/catalog-asset-detail-page/catalog-asset-detail-page.component.html#L25) | `<p>Loading…</p>` |
| [catalog-lineage.component.html:16](../src/app/features/data-catalog/components/catalog-lineage/catalog-lineage.component.html#L16) | `Tracing…` |
| [quality-pipeline-page.component.html:40](../src/app/features/quality-pipeline/containers/quality-pipeline-page/quality-pipeline-page.component.html#L40) | `<p>Loading…</p>` |

`src/app` のテンプレート全体を見ても、スケルトン（結果の形を先に描いて中身だけ後から埋める表現）は0件である。取り込み領域には画面全体を覆う [`sm-spinner`](../src/app/webapp-common/shared/ui-components/overlay/spinner/spinner.component.ts) があるが、これは `selectIsLoading` に繋がった大域の1つで、自作画面は使っていない。

このため、読み込みの前後で2つのことが起きる。1行だった領域が数十行の表に変わってレイアウトが跳ねること、そして読み込みが数百ミリ秒で終わる場合に「Loading…」が一瞬だけ点滅することである。

## なぜ変えるか

待ち時間の表示には、読み手に答えるべき問いが2つある。「いま動いているのか」と「どれくらいの量が来るのか」である。1行の文字は前者にしか答えない。

結果の形をあらかじめ描くと、後者にも答えられる。行の高さと列の幅が先に決まるので、到着時に要素が動かない。表が主役の画面では、この跳ねがそのまま誤クリックになる。

短い読み込みで表示を出さない判断も要る。`sm-spinner` は [spinner.component.ts:31-32](../src/app/webapp-common/shared/ui-components/overlay/spinner/spinner.component.ts#L31) で `debounce` を掛け、消えるときだけ 200ms 遅らせている。自作画面にはこの種の閾値が無い。

## 解決とみなす状態

1. 表・定義リスト・鎖の3つの形に対して、共有のスケルトン部品が1つある。`shared/` に置き、`data-catalog` と `quality-pipeline` の両方から呼ぶ
2. 読み込みの開始から 200ms 以内に終わった場合、待ち時間の表示を出さない
3. 一度表示したら最低 400ms は出したままにする（点滅の防止）
4. スケルトンは `aria-hidden="true"` とし、読み上げる側へは [04](./04_操作の結果を画面と支援技術の両方へ返す.md) の live region から状況を伝える
5. 2度目以降の読み込み（絞り込みの変更など）では、既存の結果を消さずに薄く表示して上に読み込み表示を重ねる。空に戻さない

## 変更の範囲

* 追加：`src/app/webapp-common/shared/components/skeleton/`（または自作側の `shared/`。置き場は [18](./18_自作画面と取り込み画面の見た目を揃える.md) の判断に合わせる）
* 変更：上表の4テンプレートと、対応する `.scss`
* 変更：`loading` を受ける入力の意味を「読み込み中」から「表示すべき待ち状態」へ変える場合、閾値の判定を container に置く

## 確かめ方

* 単体：閾値の判定（200ms 未満では出ない、出たら 400ms は消えない）を純関数として確かめる
* E2E：既存の [e2e/data-catalog.spec.ts](../e2e/data-catalog.spec.ts) に、絞り込みを変えたときに表の行数が0へ落ちないことを足す。E2E の枠は 29/30 で埋まっている（[BL-09](../docs/backlog/09_E2Eと初期束の余裕.md)）ため、新規ファイルではなく既存への追加にする
