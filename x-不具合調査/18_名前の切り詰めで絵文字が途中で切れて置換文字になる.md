## 症状

`あ` を76個、`😀`、`い` を10個並べた名前（UTF-16 で88）のタスクでクローンのダイアログを開くと、見出しは `ああ…あ�...` と表示される。見出しの末尾の文字の符号位置は `3042`・`3042`・`d83d`・`2e`・`2e`・`2e` で、`😀`（`d83d de00`）の前半だけが残っている。

## 再現手順

モック API で行う。

1. 上の名前のタスクの詳細でメニューから Clone を選ぶ
2. ダイアログの見出し「A draft copy of … will be created.」の名前の末尾が `�...` になる

スクリプトは [scripts/p2c-surrogate-truncate.spec.ts](./scripts/p2c-surrogate-truncate.spec.ts)。

## 期待する動作

切り詰めても絵文字は欠けず、`ああ…あ😀...` のように表示される。

## 原因

JavaScript の文字列の `length`・`slice`・`substring`、Angular の `slice` パイプは UTF-16 の単位で数えて切る。絵文字など U+10000 以上の文字は2単位（サロゲートペア）で、境界がその間に来ると前半だけが残る。前半だけのサロゲートは表示できず、`�` になる。

## 対策案

コードポイント単位で切り詰める共通の関数（`Array.from(value).slice(0, n).join('')`、または `Intl.Segmenter` で書記素単位）を作り、上の箇所で使う。テンプレートの `slice` パイプの箇所は、同じ処理のパイプに置き換える。関数とパイプの追加、各箇所の置き換えで「小」とした。

## 検証範囲

- 確認したこと：Playwright（Chromium、モック API）で、クローンのダイアログの見出しに前半だけのサロゲートが残り `�` と表示されること
- 確認していないこと：ほかの箇所の画面上の症状（同じ切り詰め方のため同じになると判断した）。CSV の保存名に置換文字が入ったときのブラウザ・OS ごとの扱い。結合文字や異体字セレクタ（書記素の途中で切れる場合）
- 由来：上の表のファイルは比較資料で上流と一致する
