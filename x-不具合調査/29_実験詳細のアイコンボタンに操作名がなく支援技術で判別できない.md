## 症状

モック API で実験詳細を表示し、[axe](https://github.com/dequelabs/axe-core) を `sm-experiment-info-header` に限定して実行した。critical の `button-name` 違反が5ボタンに出た。

| 対象 | 操作 |
|---|---|
| `sm-inline-edit` の鉛筆 | 名前を編集 |
| `descriptionIcon` | 説明を開く |
| `fullscreenIcon` | 詳細を全画面にする |
| `menuIcon` | 操作メニューを開く |
| `Cross Button` | 詳細を閉じる |

`smTooltip` の文言は hover 用で、ボタンの accessible name にはならない。ヘッダー全体には、menu trigger を `span` に付けたことによる `aria-allowed-attr` 違反も1件出る。

## 再現手順

1. 実験詳細を開く
2. Playwright の [scripts/p2j-inline-edit-and-axe.spec.ts](./scripts/p2j-inline-edit-and-axe.spec.ts) を実行する
3. axe の結果で `button-name` と `aria-allowed-attr` が出る。前者は5対象、後者はタグメニュー用の `span` である

## 原因

- 共通の [inline-edit.component.html:12](../src/app/webapp-common/shared/ui-components/inputs/inline-edit/inline-edit.component.html#L12) の鉛筆ボタンはアイコンだけで、操作名を持たない
- [experiment-info-header.component.html:35](../src/app/webapp-common/experiments/dumb/experiment-info-header/experiment-info-header.component.html#L35)、[同:74](../src/app/webapp-common/experiments/dumb/experiment-info-header/experiment-info-header.component.html#L74)、[同:102](../src/app/webapp-common/experiments/dumb/experiment-info-header/experiment-info-header.component.html#L102) も同様である
- [experiment-menu.component.html:2](../src/app/webapp-common/experiments/shared/components/experiment-menu/experiment-menu.component.html#L2) のメニューボタンも同じ
- [experiment-info-header.component.html:122](../src/app/webapp-common/experiments/dumb/experiment-info-header/experiment-info-header.component.html#L122) の空の `span` に `MatMenuTrigger` が ARIA 属性を付けるが、`span` 自体に適切な role がない

## 影響範囲と同種箇所

- 実験詳細とモデル詳細は同じ `sm-inline-edit` を使うため、名前編集の鉛筆は両方で発生する
- `src/app/webapp-common` の `mat-icon-button` は107個中1個しか `aria-label` / `aria-labelledby` / `title` を明示していない。すべてが違反とは限らないが、同じ確認を共通部品と各画面に広げる必要がある
- `aria-allowed-attr` の `span` trigger はモデル詳細にも同じ構造がある

## 対策案

アイコンボタンには操作内容を示す `aria-label` を付ける。共通の鉛筆は用途を input で受け取り、呼び出し側で「実験名を編集」「モデル名を編集」などを渡せるようにする。タグメニューの非表示 trigger は、`button type="button"` に替えて適切なラベルを付けるか、プログラムから直接開くことで ARIA 属性を非対話要素へ付けないようにする。

## 検証範囲

- 確認したこと：Playwright（Chromium）でモック API の実験詳細ヘッダーを組み立て、axe 4.13.0 の違反対象を確認した
- 確認していないこと：全画面・全ダイアログの axe 検査、実スクリーンリーダーでの読み上げ
- 由来：対象ファイルは比較資料で実質差分に含まれない
