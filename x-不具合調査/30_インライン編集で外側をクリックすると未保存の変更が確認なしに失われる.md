# インライン編集で外側をクリックすると、未保存の変更が確認なしに失われる

| 項目 | 内容 |
|---|---|
| カテゴリー | 操作 |
| 不具合内容 | 名前などのインライン編集で値を変更した後、部品外をクリックすると即座に取消となり、確認も復元手段もない |
| 期待動作 | 未保存の変更がある場合は保存・破棄・続行を選べる。少なくとも、外側クリックで無条件に破棄しない |
| 直さないと困ること | ポインターの誤操作や、ほかの情報を確認するためのクリックだけで入力内容が失われる |
| 修正規模 | 中 |

| 項目 | 内容 |
|---|---|
| 画面 | 実験・モデルなど、`sm-inline-edit` を使う画面 |
| 観点 | J（操作性とアクセシビリティ） |
| 重大度 | S3 |
| 確度 | 再現済み |
| 由来 | 上流 |
| 発生条件 | 編集値を変更し、保存または CANCEL を選ぶ前に部品外をクリックする |
| 関連 | [03](./03_インライン編集で変換取消のEscにより編集全体が取り消される.md)（Esc による取消）、[29](./29_実験詳細のアイコンボタンに操作名がなく支援技術で判別できない.md)（同じ部品のアクセシビリティ） |

## 症状

実験詳細の名前を `Edited but not saved` に書き換え、部品外へ click を送ると、編集モードが閉じた。編集を開き直すと元の `Task A` に戻っており、`tasks.update` は送られない。値を保存しなかったことは分かるが、変更を破棄する確認は表示されない。

## 再現手順

1. 実験詳細の名前をクリックして編集を始める
2. 値を書き換える
3. 保存ボタンまたは CANCEL を押さず、画面の別の場所をクリックする
4. 編集が閉じ、変更した値は失われる

Playwright の再現は [scripts/p2j-inline-edit-and-axe.spec.ts](./scripts/p2j-inline-edit-and-axe.spec.ts) にある。モック API を使うため、実データは変更しない。

## 原因

[inline-edit.component.ts:26](../src/app/webapp-common/shared/ui-components/inputs/inline-edit/inline-edit.component.ts#L26) は `document:click` を常時購読し、編集状態なら [同:72](../src/app/webapp-common/shared/ui-components/inputs/inline-edit/inline-edit.component.ts#L72) の `stopEditing()` から `inlineCanceled()` を呼ぶ。`inlineCanceled()` は [同:84](../src/app/webapp-common/shared/ui-components/inputs/inline-edit/inline-edit.component.ts#L84) で元の値を復元して編集を閉じるが、変更有無を確認しない。

編集中の部品内クリックだけは [inline-edit.component.html:6](../src/app/webapp-common/shared/ui-components/inputs/inline-edit/inline-edit.component.html#L6) で伝播を止めるため、外側クリックだけが無条件取消になる。

## 影響範囲と同種箇所

- `sm-inline-edit` を使う実験名、モデル名、説明などで共通して発生する
- Escape でも同じ `inlineCanceled()` を呼ぶ。IME の変換取消と衝突する件は [03](./03_インライン編集で変換取消のEscにより編集全体が取り消される.md) として別に登録している
- 編集セクション（`sm-editable-section`）は外側クリックではなく Escape で取消するため、本件とは別の操作である

## 対策案

外側クリックを取消の入口にしないのが第一案である。保存・CANCEL・Escape だけで明示的に終える。外側クリックで閉じる UX を残す必要がある場合は、変更前後を比較し、差分があれば破棄確認ダイアログを出す。再利用部品なので、既存の利用画面すべてでクリック外し・フォーカス移動・IME 操作を回帰確認する。

## 検証範囲

- 確認したこと：Playwright（Chromium）とモック API で、実験詳細の名前を変更後に外側クリックすると、保存要求なしで元値へ戻ることを確認した
- 確認していないこと：全利用画面、タッチ端末、支援技術が発生させる focusout / click の組合せ
- 由来：`inline-edit.component.ts`・HTML は比較資料で実質差分に含まれない
