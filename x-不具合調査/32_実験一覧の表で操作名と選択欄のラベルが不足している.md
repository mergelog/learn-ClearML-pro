# 実験一覧の表で、操作名と選択欄のラベルが不足している

| 項目 | 内容 |
|---|---|
| カテゴリー | 操作 |
| 不具合内容 | 実験一覧の列ソート・フィルタ・行メニュー・一括選択・行選択が、支援技術に操作目的を伝えられない |
| 期待動作 | アイコンだけのボタンとチェックボックスに、対象列・対象行を含む一意の accessible name を付ける。メニューを開く要素はキーボード操作可能な button にする |
| 直さないと困ること | スクリーンリーダー利用者が「名称を昇順に並べる」「このタスクを選ぶ」「この行のメニューを開く」と区別できず、キーボードだけで操作を完結できない |
| 修正規模 | 中 |

| 項目 | 内容 |
|---|---|
| 画面 | 実験管理 > 一覧（共通 `sm-table`、`sm-table-filter-sort`、`sm-menu`） |
| 観点 | J（操作性とアクセシビリティ） |
| 重大度 | S2 |
| 確度 | 再現済み（axe） |
| 由来 | 上流 |
| 発生条件 | スクリーンリーダーまたはキーボードで、一覧の表を操作する |
| 関連 | [29](./29_実験詳細のアイコンボタンに操作名がなく支援技術で判別できない.md)（詳細ヘッダーの同種問題） |

## 症状

実験一覧の `sm-experiments-table` に axe 4.13.0 を実行すると、critical の違反を3種類検出した。

| axe ルール | 操作 | 検出内容 |
|---|---|---|
| `button-name` | 列のソート、列フィルタ、行の3点メニュー | テキスト・`aria-label`・説明がないため、何を操作するボタンか分からない |
| `label` | 一括選択、各行の選択 checkbox | 入力に label / `aria-label` がなく、選択対象が分からない |
| `aria-allowed-attr` | 一括選択の横にあるドロップダウン | `div` に Material のメニュートリガー属性を付けており、許されない ARIA 属性になる |

## 再現手順

1. タスク一覧を開く
2. axe を `sm-experiments-table` に限定して実行する
3. `button-name`、`label`、`aria-allowed-attr` がいずれも critical として報告される

Playwright の検査は [scripts/p3-experiments-navigation.spec.ts](./scripts/p3-experiments-navigation.spec.ts) にある。実バックエンドの調査用プロジェクトを読み取るだけで、データは変更しない。

## 原因

- [table-filter-sort.component.html:3](../src/app/webapp-common/shared/ui-components/data/table/table-filter-sort/table-filter-sort.component.html#L3) のソートボタンはアイコンだけで、列名を含む accessible name がない
- 同:23 の `sm-menu` は、[menu.component.html:1](../src/app/webapp-common/shared/ui-components/panel/menu/menu.component.html#L1) で空の `header()` とアイコンだけの button を作るが、`buttonTooltip()` も accessible name に結び付けていない
- [table.component.html:172](../src/app/webapp-common/shared/ui-components/data/table/table.component.html#L172) の行メニューもアイコンだけである
- [experiments-table.component.html:60](../src/app/webapp-common/experiments/dumb/experiments-table/experiments-table.component.html#L60) と [同:166](../src/app/webapp-common/experiments/dumb/experiments-table/experiments-table.component.html#L166) の `mat-checkbox` は空のままで label がない
- [同:70](../src/app/webapp-common/experiments/dumb/experiments-table/experiments-table.component.html#L70) は、button ではない `div` に `matMenuTriggerFor` を付けている

## 影響範囲と同種箇所

- `sm-table` を使うタスク、モデル、キュー、ワーカーなどの一覧に、行メニューの問題が波及する
- `sm-table-filter-sort` を使う一覧では、列ソートとフィルタの問題が波及する
- タスク一覧の行 checkbox は固有テンプレートだが、同じ空の `mat-checkbox` がカード表示にもある

## 対策案

共通部品で次を実施する。

1. ソートには `aria-label="{列名}を並べ替え"`、フィルタには `aria-label="{列名}を絞り込む"`、行メニューには `aria-label="{行名}の操作"` を渡す
2. 一括選択と各行の checkbox に `aria-label` を渡す
3. ドロップダウンの `div` を `button type="button"` に置換し、対応するラベルを付ける
4. 主要な一覧の axe 検査を自動テストへ追加する

## 検証範囲

- 確認したこと：Playwright（Chromium）で実験一覧を読み込み、axe の critical 違反を確認した
- 確認していないこと：全利用画面、実際のスクリーンリーダーでの読み上げ、カード表示時のすべての操作
- 由来：対象の共通部品は比較資料で実質差分に含まれない
