# 共通のアイコン操作に操作名がない

| 項目 | 内容 |
|---|---|
| カテゴリー | 操作 |
| 不具合内容 | 表示形式切替・検索・正規表現・更新・フィルタ解除・CSV ダウンロードのアイコン操作が accessible name を持たない |
| 期待動作 | 操作の意味と状態を表す `aria-label` を各アイコンボタンに付ける |
| 直さないと困ること | スクリーンリーダー利用者が一覧の検索、表示切替、更新、ダウンロード、フィルタ解除を区別して実行できない |
| 修正規模 | 中 |

| 項目 | 内容 |
|---|---|
| 画面 | レポート、エンドポイントほか、共通部品を使う一覧 |
| 観点 | J（操作性とアクセシビリティ） |
| 重大度 | S2 |
| 確度 | 再現済み（axe） |
| 由来 | 上流 |
| 発生条件 | スクリーンリーダーまたはキーボードで、一覧のヘッダー操作を行う場合 |
| 関連 | [32](./32_実験一覧の表で操作名と選択欄のラベルが不足している.md)（表の列・行操作）、[34](./34_ヘッダーのアイコン操作とプロフィールメニューを支援技術で判別・操作できない.md) |

## 症状

axe 4.13.0 の critical `button-name` が、実バックエンドの次の画面で出る。

| 画面 | 対象 |
|---|---|
| レポート | 表示形式切替、検索を開くボタン |
| エンドポイント | 表示形式切替、検索、フィルタ解除、CSV ダウンロード、更新 |

表の列ソート・フィルタは既登録の[32](./32_実験一覧の表で操作名と選択欄のラベルが不足している.md)に含め、この資料では一覧ヘッダーの共通操作を扱う。

## 再現手順

1. レポートまたはエンドポイント一覧を開く
2. `npx playwright test -c x-不具合調査/scripts/playwright.config.ts p3-later-screens.spec.ts --grep 'axe'` を実行する
3. `/reports` と `/endpoints/active` の `button-name` を確認する

## 原因

- [button-toggle.component.html:10](../src/app/webapp-common/shared/ui-components/inputs/button-toggle/button-toggle.component.html#L10) はアイコンだけの `mat-button-toggle` に選択肢の `label` を accessible name として渡していない
- [common-search.component.html:2](../src/app/webapp-common/common-search/containers/common-search/common-search.component.html#L2) の検索・取消ボタンと[同:32](../src/app/webapp-common/common-search/containers/common-search/common-search.component.html#L32) の正規表現ボタンに名前がない
- [refresh-button.component.html:8](../src/app/webapp-common/shared/components/refresh-button/refresh-button.component.html#L8)、[clear-filters-button.component.html:2](../src/app/webapp-common/shared/components/clear-filters-button/clear-filters-button.component.html#L2)、[serving-header.component.html:22](../src/app/webapp-common/serving/serving-header/serving-header.component.html#L22) も同じである

## 影響範囲と同種箇所

これらは共通部品であり、レポート・エンドポイントに限らず、同じ部品を使うプロジェクト、パイプライン、データセット、モデル、実験の一覧にも波及する。アイコンだけの表の操作は[32](./32_実験一覧の表で操作名と選択欄のラベルが不足している.md)で別途扱う。

## 対策案

共通部品の入力値・状態から `aria-label` を設定する。例として、表示形式切替は選択肢の `label`、検索は「検索を開く」／「検索をクリア」、更新は「更新」または「自動更新の設定」、フィルタ解除は「すべてのフィルタを解除」、ダウンロードは「CSV をダウンロード」とする。各一覧を axe で回帰検査する。

## 検証範囲

- 確認したこと：Playwright（Chromium）と axe 4.13.0 でレポート・エンドポイントの実画面を検査した
- 確認していないこと：共通部品の全利用画面、実スクリーンリーダーでの読み上げ
- 由来：対象ファイルは比較資料で実質差分に含まれない
