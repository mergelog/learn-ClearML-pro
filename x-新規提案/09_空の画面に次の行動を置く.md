## いま画面で起きていること

自作画面には「何も無い」状態が6つある。どれも1文の説明で終わり、そこから動く手段が画面に無い。

| 場所 | 文言 | 次の行動 |
| --- | --- | --- |
| [catalog-assets-table.component.html:50](../src/app/features/data-catalog/components/catalog-assets-table/catalog-assets-table.component.html#L50) | The catalog is empty. Register a Dataset or run the pipeline first. | 文章のみ。パイプラインの画面への導線は無い |
| [同:48](../src/app/features/data-catalog/components/catalog-assets-table/catalog-assets-table.component.html#L48) | Nothing matches these filters. Clear one of them to widen the search. | 「Clear」は上の絞り込みにあるが、ここからは押せない |
| [catalog-lineage.component.html:18](../src/app/features/data-catalog/components/catalog-lineage/catalog-lineage.component.html#L18) | Nothing links this asset to a dataset or a model. | — |
| [quality-pipeline-page.component.html:42](../src/app/features/quality-pipeline/containers/quality-pipeline-page/quality-pipeline-page.component.html#L42) | No run yet. | 起動フォームは同じ画面の上にある |
| [evaluation-scores-table.component.html:25](../src/app/features/quality-pipeline/components/evaluation-scores-table/evaluation-scores-table.component.html#L25) | No scores yet. | 評価がまだなのか、失敗したのかを区別しない |
| [production-model-card.component.html:19](../src/app/features/quality-pipeline/components/production-model-card/production-model-card.component.html#L19) | No model has been promoted to production yet. | 昇格の手段は画面に無い（[16](./16_昇格と切り戻しを画面から行えるようにする.md)） |

例外が1つある。起動元のパイプラインが無いときの案内は、実行すべきコマンドを示している。

```
No pipeline to start from. Submit one with
pnpm ml:pipeline -- --dataset-version 1.0.0 --submit
```

［[start-run-form.component.html:9-14](../src/app/features/quality-pipeline/components/start-run-form/start-run-form.component.html#L9)］

ただしこれは `<code>` の中の文字で、コピーする手段が無い。取り込み領域の空状態は同じ問題を別の形で解いていて、[dataset-empty.component.html:22-29](../src/app/webapp-common/datasets/dataset-empty/dataset-empty.component.html#L22) は `sm-code-editor` にコピーボタンを付け、文書へのリンクを添えている。

## なぜ変えるか

空の画面は、初めて使う利用者が最も長く見る画面である。ここに書いてあることが、その人にとっての操作説明になる。

「何も無い」には種類がある。まだ作っていない、絞り込んだ結果として無い、権限が無くて見えない、読み込みに失敗した、の4つは別のものである。いまの実装はこのうち2つ（`no-match` と、それ以外）を区別している（[data-catalog.selectors.ts](../src/app/features/data-catalog/state/data-catalog.selectors.ts) の `selectEmptyReason`）。区別したうえで、行き先を出していない。

## 解決とみなす状態

1. 空状態の表示を、文章・行動・補足の3つを持つ形に揃える。行動はボタンかリンクで、押すと状況が変わる
2. `no-match` では絞り込みを解除するボタンを空状態の中に置く。いまある Clear と同じ action を流す
3. 台帳が空のときは、パイプラインの画面へのリンクを置く。台帳と品質パイプラインは同じアプリの中にあり、外部の文書を読ませる必要は無い
4. コマンドを案内する箇所はコピーできるようにする。[`CopyClipboardComponent`](../src/app/webapp-common/shared/ui-components/indicators/copy-clipboard/copy-clipboard.component.ts) を使う
5. `No scores yet.` を、評価ステップの状態で分ける。まだ走っていない／走っている／終わったが指標が読めなかった、の3つは利用者の次の行動が違う（3つめは [02](./02_失敗したときに次の一手を示す.md) の再試行に繋がる）

## 変更の範囲

* 変更：上表の6箇所
* 変更：`quality-pipeline` の state に、評価ステップの状態から「指標がまだ無い理由」を導く selector を足す。いま Effects は指標の読み取り失敗を握り潰している（[quality-pipeline.effects.ts:173](../src/app/features/quality-pipeline/state/quality-pipeline.effects.ts#L173) の `catchError(() => EMPTY)`）ため、理由を state へ渡す経路が要る

## 確かめ方

* 単体：`selectEmptyReason` の拡張と、指標が無い理由の導出
* E2E：[e2e/accessibility.spec.ts:48-56](../e2e/accessibility.spec.ts#L48) は既に空の画面を見ている。行動のボタンを足した後も違反0件を維持する
